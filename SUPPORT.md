# Support

Paracoat Dispatch Studio is an early-stage community prototype.

- For reproducible bugs, open a GitHub issue using the bug report template.
- For product ideas, open an issue using the feature request template.
- For setup, review the README quick-start and Docker sections.
- For security issues, follow [SECURITY.md](SECURITY.md) and do not post sensitive details publicly.

Never attach real customer or shipment data, credentials, database files, or private route information to public issues.
